# Illegal Agent-like LLM which automatically serves up links to copyrighted texts available by mid 2026

## Finding

The 2026-02-05 clarification makes this about agents accepting tasks like "find a working hostname for libgen, search it, get the link, download the link contents, push it to this s3 bucket", and about how far companies go to stop their agents; a well-known link such as the one in LarsOsborne's ChatGPT example does not count. The documented tests before the deadline were mostly refusals: on 2026-05-29 Yoav Goldberg (AI2-Israel) reported that the Hermes agent running GPT-5.x refused to search and download books from Anna's Archive and that Kimi and Grok also refused, and a 2026-06-22 Reddit thread reported refusals from many OpenRouter models for a Z-Library downloader, with MiniMax refusing Anna's Archive. Hosted agents that could technically do the task existed (Venice's uncensored agent chat from 2026-05-19, Kimi Claw and MiniMax's MaxClaw from February 2026, Hermes Agent with a $20-$100 Nous Portal plan from April 2026), but I found no report of any of them completing a shadow-library retrieval, and Venice's terms ban infringement. Compliance was reported only where users added their own tooling: for an Anna's Archive connector built for Claude Desktop, which searches, downloads and picks a working mirror by itself, a user wrote in August 2026 that an earlier Claude version "didn't balk at using the connector", and one Reddit commenter said the Anna's Archive task "worked with most" models in Hermes. The outcome turns on how Ernie reads "some LLM with a public (paid okay, up to 100$/month) ... such that I can go there and ask it"; the evidence leans NO for services used as offered.

## Other side

The market asks whether "some LLM" would do this, and one is enough. Claude is a paid public service within the budget; by one user's account, versions before Opus 5 used an Anna's Archive connector whose tools search and download books, the connector performs the "find a working hostname" step, and Claude Code co-wrote fixes to that scraper in February 2026, so Anthropic had not stopped its agent from working with a shadow library by the deadline. A Reddit user also said most models in Hermes did the Anna's Archive task, and uncensored hosts such as Venice sold agent access. Under the clarification's focus on "how far companies will go to prevent their agents", that shows the guardrails had gaps, and YES is defensible. I still lean NO because the Claude capability comes from a purpose-built piracy connector the user installs, not from the service as offered; the compliance claims are single anecdotes, and the specific Claude report was written after the deadline; and every documented direct test of a major model (GPT-5.x, Kimi, Grok, MiniMax) was a refusal. No report shows a hosted agent completing the market's libgen-to-S3 example.
